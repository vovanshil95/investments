# Investments — анализ облигаций Московской биржи

Анализ облигаций через публичное API Т‑Банка (Тинькофф Инвестиции).
Стратегия по умолчанию — поиск бумаг с **ежемесячным купоном**: 12 выплат в год, купон ≥ 2% от цены, цена ≥ 97% номинала.

## Пайплайн

Все данные (список облигаций + детали по каждой) забираются **живьём с API при каждом запуске
блокнота** — никаких промежуточных CSV нет, поэтому не бывает рассинхрона схемы между старыми
и новыми данными.

```
fetch_bonds.py  ─►  fetch_bonds_detail.py  ─►  filter_bonds.py  ─►  графики и топы
  тикеры (в памяти)   детали (в памяти)          шортлист (в памяти)     в самом блокноте
```

| Модуль | Что делает |
|---|---|
| `fetch_bonds.py` | `fetch_tickers()` — список всех облигаций с биржи (постранично) |
| `fetch_bonds_detail.py` | `fetch_details(tickers)` — детали по каждой бумаге (~45 полей) |
| `filter_bonds.py` | `apply_filter(df, ...)` + `add_securitization(df)` — стратегия и флаг залога |
| `bonds_analysis.ipynb` | всё вместе: настройки → загрузка → топы по группам надёжности → графики |
| `fetch_operations.py` | токен в `.env` → `operations.csv`: история операций по своему счёту (T-Invest API) |
| `bond_pnl.py` | токен в `.env` → `bond_pnl.csv`: реализованный P&L по облигациям (капитал vs НКД/купоны) |

## Запуск

```bash
pip install -r requirements.txt
jupyter lab bonds_analysis.ipynb   # Kernel → Restart & Run All
```

Полный прогон занимает **~1–1.5 часа** (детали по ~1400+ бумагам, с задержкой между запросами
против троттлинга API). Вторая ячейка блокнота — «Настройки»: все пороги стратегии и вид
отчёта вынесены туда как обычные Python-константы, меняешь значение и перезапускаешь ячейки
ниже:

```python
MIN_COUPON_QTY_PER_YEAR = 12       # только ежемесячный купон (12 выплат в год)
MIN_COUPON_TO_PRICE_PCT = 0.02     # купон >= 2% от текущей цены
MIN_PRICE_TO_FACE_PCT = 0.97       # цена >= 97% от номинала
EXCLUDE_QUAL_INVESTOR = True       # исключить бумаги для квалифицированных инвесторов
EXCLUDE_FLOATING_COUPON = True     # исключить облигации с плавающим купоном
EXCLUDE_SECURITIZED = True         # исключить облигации с залоговым обеспечением (СФО)
EXCLUDE_PREMIUM_NEAR_MATURITY = True   # исключить "цена выше номинала при близком погашении"
PREMIUM_NEAR_MATURITY_MAX_YEARS = 0.5  # порог "близкого" погашения, лет

TOP_N = 10                        # сколько лучших облигаций показывать в каждой группе оценки
MIN_BONDS_PER_SECTOR_CHART = 2    # мин. кол-во бумаг в секторе для графика среднего купона
```

## История операций по своему счёту

`fetch_operations.py` использует официальный [T-Invest API](https://developer.tbank.ru/invest/intro/intro)
(отдельный от публичного справочника облигаций, нужен свой токен).

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install --no-deps git+https://github.com/RussianInvestments/invest-python.git

echo "TINVEST_TOKEN=твой_токен" > .env   # токен из приложения Т-Инвестиции → Настройки → API
.venv/bin/python fetch_operations.py     # -> operations.csv
```

`tinkoff-investments` временно в карантине на PyPI, поэтому ставится напрямую из GitHub, и
изолированно в `.venv` — чтобы не тянуть protobuf/cachetools в общее python-окружение и не
ломать другие проекты. `.env` и `operations.csv` в `.gitignore` — токен и история операций
никогда не попадают в git.

## P&L по облигациям

`bond_pnl.py` считает реализованный результат по облигациям отдельно по двум статьям:

- **капитал** — прибыль/убыток от продаж и погашений (полных и частичных) относительно
  средневзвешенной цены покупки (чистая цена + комиссия брокера, без НКД);
- **НКД/купоны** — накопленный купонный доход, уплаченный при покупке и полученный при
  продаже, плюс сами купонные выплаты.

Средняя цена покупки всегда считается по **всей** истории сделок. Флаг периода (`--month`
или `--from`/`--to`) ограничивает только события реализации — продажи, погашения, купоны —
покупки в него не попадают, только участвуют в расчёте средней цены.

```bash
.venv/bin/python bond_pnl.py --month 2026-07              # за месяц
.venv/bin/python bond_pnl.py --from 2026-01-01 --to 2026-12-31   # произвольный период
.venv/bin/python bond_pnl.py                               # по умолчанию — текущий месяц
```

При частичном погашении (амортизации) доля возвращённого номинала уточняется через
`InstrumentsService.BondBy`, и средняя цена уменьшается пропорционально этой доле.

## Заметки

- API Т‑Банка публичное, авторизация не нужна.
- Поле `securitizationFlag` в API **неполное**: у части выпусков СФО стоит `False`. Поэтому залоговые бумаги отбираются также по имени эмитента «СФО» (Специализированное финансовое общество) — см. `filter_bonds.add_securitization`.
- Данные всегда актуальны на момент запуска блокнота — снимков рынка не сохраняется.
